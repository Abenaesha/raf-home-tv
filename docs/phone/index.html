    Using an iPhone? Set up "Send to TV"
    1. Open Shortcuts, tap +, name it Send to TV.
    2. Tap the i (details) and turn on Show in Share Sheet; accept URLs and Text.
    3. Add Get Contents of URL. URL:
    4. Set Method to POST and Request Body to JSON with two Text fields: kind = share, and url = Shortcut Input.
    5. Optional: add Show Notification "Sent to TV".
    Then share from Safari, YouTube or anywhere and pick Send to TV.
